# YuvaIntern Task 5 — Analytics Report & Insights Documentation

## Project
**Restaurant Bill and Tip Analysis**

## Objective
Demonstrate a professional reporting workflow: define business questions, analyze data, create visualizations, interpret findings, prepare an executive summary, and provide actionable recommendations.

## Dataset
Seaborn `tips` teaching dataset. It includes total bill, tip, sex, smoker indicator, day, time, and party size. This is an educational dataset, not a complete operational dataset from a specific business.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook.

## Analysis included
- Data structure, types, descriptive statistics, missing values and duplicate checks
- Derived tip percentage metric
- Executive metrics
- Day and meal-time comparisons
- Bar chart, histogram, scatter plot and line chart
- Correlation matrix and smoker-group comparison
- Data-driven findings, executive summary, limitations and recommendations

## Run
Install dependencies: `pip install -r requirements.txt`
Open `Task_5_Analytics_Report_Insights.ipynb` in Jupyter and run all cells from top to bottom.

## Dataset note
The notebook loads the dataset through `sns.load_dataset("tips")`, which may require internet access the first time it is loaded.
